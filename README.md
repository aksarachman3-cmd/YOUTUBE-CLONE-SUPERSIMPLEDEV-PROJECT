# YouTube Clone Project

This is a project made by me to increase my HTML and CSS skills. I'm creating it with the help of the SuperSimpleDev tutorial video.

**Status**: ✅ Completed (19 November 2026)

## Source

**YouTube Link**: <https://www.youtube.com/watch?v=G3e-cpL7ofc&t=14963s>

## Features

- Fixed header with menu icon, logo, search bar, and action icons
- Video grid with 4 columns (thumbnail, channel picture, title, channel name, and stats)
- Fixed sidebar with menu icons

## Built With

- HTML
- CSS (Flexbox and Grid)
- Roboto font (Google Fonts)
